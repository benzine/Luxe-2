LUXE HAIR STUDIO — COMPLETE SOURCE CODE
=======================================

This archive contains EVERY source file of the website (31 files),
byte-for-byte as of the build that produced it: all components, styles,
config, the Vite build config, package manifests, and the recovery locks.

TO RUN LOCALLY:
  1. npm install
  2. npm run dev            (development server)
     — or —
     npm run build && npm run preview   (production preview)

TO RE-EMIT THE OTHER ARTIFACTS:
  npm run build
    → dist/luxe-rebuild-paste.txt   (single paste-back recovery file)
    → dist/luxe-compiled-site.zip   (deployable compiled site)
